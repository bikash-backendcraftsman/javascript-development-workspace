# JavaScript Development Workspace

Small JavaScript learning scripts, grouped by language topic. Each directory under `JavascriptLearning` is a set of standalone files you can run with Node. Folder names are kept as they are on disk so local paths stay the same.

## Layout

- `JavascriptLearning/Javascript_Variable` — `let`, `const`, and variable examples
- `JavascriptLearning/Javascript_Function` — regular functions and arrow functions
- `JavascriptLearning/Javascript_Scope` — scope examples
- `JavascriptLearning/Javascript_Closure` — closure examples
- `JavascriptLearning/Javascript_This_Function` — `this` binding
- `JavascriptLearning/Javascript_CallBack_Function` — callbacks, filtering, and word-length examples
- `JavascriptLearning/Javascript_Array` — creating and modifying arrays
- `JavascriptLearning/Javascript_Object` — objects, nesting, and iteration
- `JavascriptLearning/TypeCoersion_And_Conversion` — implicit coercion and explicit conversion
- `JavascriptLearning/Javascript_Exercise` — practice sessions
